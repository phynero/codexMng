Getting started with Codex Deck

  1. Add and sign in to an account

    Enter a name, then connect using the official browser sign-in or a device code. When adding another account, select it on the authorization page.

  2. Check usage and reset countdowns

    Usage refreshes every minute, and you can refresh manually at any time. Limits for different models are shown separately; select them within each account.

  3. Manage your accounts

    Rename, reconnect, or remove accounts at any time. Credentials are saved in this project’s data directory and are not uploaded to third-party servers.

  4. Switch desktop account

    Choose “Use on desktop” on a connected account. After confirmation, the app will restart and running tasks will be interrupted. This also updates the default Codex CLI or extension sign-in. Restore your previous sign-in from the desktop panel. The current-account badge reflects the sign-in saved on this computer.

Missing usage is shown as “No data.” When a countdown reaches zero, the dashboard waits for the API to confirm a reset. Percentages show the remaining allowance; the number of requests available depends on how you use Codex.
